# MORPH-Exact / MORPH-Hyper：可证明的自抽象计算原型

## 0. 结论状态

本项目已经完成一个**可运行、可复现、逐状态逐输入验证**的自抽象计算原型，但没有把尚未证明的猜想包装成定理。

已完成：

1. 一个闭合的新计算原语：开放计算单元经精确组合和最小行为商后，成为与原单元同类型的新计算原子。
2. 一个自动层级发现算法：不读取预设层级，以候选融合后真实出现的语义压缩选择器官边界。
3. 一个证明携带运行时：每次再原子化都附带完整状态映射，同态条件和商最小性由独立检查器穷尽验证。
4. 一个超边扩展：能够原子性提交“汇聚节点 + 两个成熟生产者”的三元器官，跨越二元融合的中性障碍。
5. 2,559 行 Python 核心、测试和实验代码；公开控制器、自然生成系统、随机压力测试以及完整原始 CSV/JSON。

## 1. 核心发现

传统计算系统把基本指令、状态和模块边界视为设计者预先给定的对象。MORPH 提出不同的执行规则：

> 当一组开放计算单元的联合行为存在一个更小、精确且可组合的外部行为商时，运行时把该商提升为新的计算原子；新原子继续参与同一规则，递归形成更高层原子。

对应“孤立—联系—秩序—涌现—再孤立”：

| 阶段 | 可执行对象 |
|---|---|
| 孤立 | 每个原始开放 Moore 状态机分别存在 |
| 联系 | 真实可变输出通过有类型端口驱动其他单元 |
| 秩序 | 候选区域组合后产生可测量的精确行为压缩 |
| 涌现 | 最小行为商替代整个区域，并成为同类型新机器 |
| 再孤立 | 新机器作为单个原子进入下一代候选集合 |

该闭环不是哲学比喻，而是代码中的同一个数据类型和同一个组合算子反复执行。

## 2. 计算模型

一个计算原子是开放确定性同步 Moore 传感器：

\[
M=(S,I,O,s_0,\delta,\lambda)
\]

其中：

- \(S\) 为有限状态集；
- \(I\) 为布尔输入端口集合；
- \(O\) 为布尔输出端口集合；
- \(\delta:S\times\{0,1\}^{|I|}\to S\)；
- \(\lambda:S\to\{0,1\}^{|O|}\)。

输出只依赖当前状态，因此带反馈的同步组合没有组合逻辑不动点歧义：先读取当前输出，再同时更新全部状态。

对区域 \(R\)，其接口仅保留：

1. 区域外产生、区域内消费的输入信号；
2. 区域内产生、区域外消费或被全局观察的输出信号。

区域内部信号在组合后被隐藏。

## 3. 新算法对象

### 3.1 反事实行为商

对候选区域集合 \(C=\{R_1,\dots,R_k\}\)，算法不只根据图结构猜测合并价值，而是实际执行：

\[
P_C=\operatorname{Reach}
\left(
Q(R_1)\otimes\cdots\otimes Q(R_k)
\right)
\]

再求其规范最小 Moore 商：

\[
Q_C=\operatorname{Min}(P_C)
\]

“反事实”的含义是：候选尚未真正合并，运行时先回答“若把它们视为一个原子，究竟会出现多小的精确计算原语？”

### 3.2 涌现原语增益 EPG

原型使用如下类型的评分：

\[
\operatorname{EPG}(C)
=
\log_2\frac{\prod_i |Q(R_i)|}{|Q_C|}
+\alpha\log_2\frac{|P_C|}{|Q_C|}
-\beta\Delta B_C
-\gamma\log_2(1+W_C)
\]

其中：

- 第一项度量从子原子笛卡尔积到新原子的总压缩；
- 第二项单独奖励不可观察状态合并；
- \(\Delta B_C\) 惩罚接口增长；
- \(W_C\) 是构造并验证候选的转移工作量。

EPG 不是正确性条件。正确性完全由证书决定；EPG 只决定搜索顺序。

### 3.3 再原子化证书

每次安装商机器前，生成映射：

\[
\phi:S_{P_C}\twoheadrightarrow S_{Q_C}
\]

独立检查器穷尽验证：

\[
\lambda_{P_C}(s)=\lambda_{Q_C}(\phi(s))
\]

以及对每个状态、每个输入：

\[
\phi(\delta_{P_C}(s,u))
=
\delta_{Q_C}(\phi(s),u|_{I_{Q_C}})
\]

此外使用与构造器不同的可区分状态对算法检查 \(Q_C\) 已最小。

### 3.4 成熟性与超器官

二元融合可能遇到中性障碍：聚合器与任意一个输入子树单独组合都不压缩，但三者共同组合后才产生小商。

MORPH-Hyper 检测三元超边：

\[
(A,G,B)
\]

其中 \(G\) 是仍未再原子化的汇聚原子，\(A,B\) 是两个“成熟”生产者——它们的可执行输入已不再由当前其他区域驱动。算法检查两种二元括号顺序：

\[
\operatorname{Min}(\operatorname{Min}(G\otimes A)\otimes B)
\]

和

\[
\operatorname{Min}(\operatorname{Min}(G\otimes B)\otimes A)
\]

选择峰值更小、EPG 更高者，并以两张连续证书原子性提交整个三元器官。

## 4. 算法伪代码

```text
MORPH-HYPER(network):
    P <- 每个原始单元各自构成一个区域

    while |P| > 1:
        H <- 从真实可执行信号依赖中发现二元边和成熟三元超边
        C <- 使用接口闭合度和候选规模对 H 做廉价筛选

        for candidate in shortlist(C):
            raw <- 精确构造候选的可达同步组合
            quotient, phi <- 规范 Moore 最小化并删除无关输入
            assert check_homomorphism(raw, quotient, phi)
            assert independent_minimality_check(quotient)
            score <- EPG(candidate)

        B <- 分数为正、区域互不相交的最大贪心批次
        if B 为空:
            B <- 资源预算内分数最高的一个已认证候选

        并行地将 B 中每个区域集合替换为其 quotient

    return 唯一剩余的证明携带原子
```

只有通过证书的候选可以进入批次。候选超出状态或转移预算时不会被近似安装，而是被拒绝。

## 5. 正确性结论

### 定理 1：单次再原子化保持全部未来轨迹

若 \(\phi\) 满足输出保持和转移交换，则对任意输入词 \(u_0u_1\cdots u_t\)：

\[
\operatorname{Trace}_{P_C}(u_0\dots u_t)
=
\operatorname{Trace}_{Q_C}(u_0\dots u_t)
\]

证明：对时间步归纳。初始状态由证书映射；若第 \(t\) 步状态对应，输出保持给出当前输出相同，转移交换给出下一状态仍对应。

### 定理 2：递归再原子化保持全局轨迹

开放同步组合对上述接口行为等价是合同关系。将任一区域替换为等价商，不改变任意兼容外部环境中的全局轨迹。对再原子化树上的替换次数归纳，即得最终根机与原网络行为等价。

### “100% 验证”的准确含义

本项目中的 100% 仅表示：

- 对每个被选择的有限候选，检查所有可达状态和所有输入；
- 每个商的最小性由独立算法检查；
- 小型多层网络与独立单体构造逐行为交叉验证；
- 已执行的压力测试没有失败。

它不表示已经证明一般程序的上下文等价可判定，也不表示所有未来输入模型、无限状态系统或并发语义均已覆盖。

### 6.2 隐藏形态基准

父控制器被递归实现为互相交换隐藏“心跳位”的底层机器。只有正确兄弟区域同时形成时，内部相位才从外部不可区分。算法不读取真实层级，并加入只影响结构元数据的诱饵边。

这是一个受控的**层级可识别性实验**，不是自然分布的替代品。

### 6.3 跨控制语义

同一个算法内核用于：

- 奇偶累加器；
- 模 5 计数器；
- `1011` 模式识别器；
- 握手协议；
- 交通灯；
- 交替位协议；
- 奇偶 × 握手混合控制器。

每类运行 3 个诱饵种子，均使用 64 个底层单元。

### 6.4 公开 LGSynth91 `bbara`

公开 KISS2 文件声明 4 个输入、2 个输出、10 个控制状态、60 个积项。原型将确定 Mealy 机精确状态分裂为 Moore 机并最小化为 9 状态根机，再进行递归实现和自动恢复。

### 6.5 自然系统

为避免只在“由目标反向拆出来”的实例上成功，加入两个独立正向生成系统：

1. 注册 XOR 汇聚树；
2. 三进制注册模和汇聚树。

所有内部节点均是原始状态机，未调用隐藏分裂生成器。

## 8. 与最近邻研究的精确边界

### 已经存在的内容

- Graf 与 Steffen 在 CAV 1990 已提出有限状态系统的组合式最小化；因此“边组合边最小化”绝不是本项目的新发现。
- Graf、Steffen、Lüttgen 随后利用接口规范约束组件环境，减少不可达中间状态。
- Crouzen 与 Lang 的 Smart Reduction 允许灵活组合顺序，并依据同步、隐藏和接口结构选择较好的组合。
- Biggar、Zamani、Shames 研究了从单个扁平 FSM 中计算等价 HFSM 的薄模块分解。

### MORPH 当前提出的组合

1. 输入是开放机器网络，而不是单个扁平 FSM；
2. 边界不是靠预设层级或仅靠语法连接确定；
3. 每个候选都以“实际组合后得到的规范最小行为商”作为反事实证据；
4. 商机器被提升为同类型原子并进入下一代；
5. 多个互不重叠的原子同代提交；
6. 三元超边可跨越二元中性障碍；
7. 每次安装都携带同态和最小性证书。

本次文献检索没有发现上述七项同时出现的先例，但这不是法律意义上的绝对新颖性证明。正式投稿仍需扩展系统检索、作者沟通和更严格的相关工作审查。

## 9. 为什么它具有大奖级潜力

当前代码本身不是图灵奖级成果。潜力来自它把一个长期由人类完成的元工作转化为计算原语：

> **计算机不仅执行给定原子，还能依据完整外部行为，证明并发明下一层精确原子。**

要跨越到大奖级，至少还需完成下列一项：

### 9.1 形态宽度复杂性理论

定义某网络所有合法再原子化树中最小的最大精确接口商：

\[
\operatorname{MW}(N)
=
\min_T\max_{v\in T}
\log_2 |Q(\partial v)|
\]

并证明多个传统上分散的问题在低 MW 上具有统一 FPT 算法，而其树宽或显式状态空间可以很大。

### 9.2 动态最优性定理

证明在线 MORPH 相对于知道完整未来和最优抽象树的离线算法具有多对数竞争比。

### 9.3 算法重演

让同一个无领域规则内核在真实程序中自动形成与并查集、高斯消元、协议状态压缩、数据库索引等经典算法同构的新原子，而不预先编码这些算法。

### 9.4 通用证明携带运行时

把有限 Moore 原型扩展为符号程序、并发进程、数据库查询和硬件 IR，使新原子成为可执行宏指令，并跨领域出现同一缩放律。

## 10. 当前失败与证伪条件

### 已观察失败

1. 显式布尔输入表使接口宽度以 \(2^{|I|}\) 扩张；
2. 自然三进制模和树 127 组件超过 15 分钟；
3. 自然 XOR 树 511 组件版本超过现有 Python 预算；
4. 二元 MORPH 在聚合器系统中出现中性障碍，虽由三元超边缓解，但不是一般 k 元解；
5. 当前只支持确定同步 Moore 语义。

### 核心假说应被否决的情形

- 在更广泛真实模型上，语义增益不能比结构顺序稳定预测好的边界；
- 求候选行为商总是必须先经历与单体全局状态空间同阶的爆炸；
- 任何有效压缩都依赖人工提供领域专用摘要；
- 新原子无法继续用同一个组合和证明规则递归使用；
- 形态宽度不能与已有树宽、模块分解宽度或通信复杂性参数形成非平凡区别。

---

## 11. 下一项最关键研究

优先级最高的不是继续堆 benchmark，而是实现：

> **符号化、证明携带的行为商。**

建议将显式转移表替换为 BDD/AIG/SAT 表示，并让证书变为：

- 双向仿真关系；
- SAT 不可满足证明；
- 可检查的分区细化日志；
- 接口相关性的符号消元证明。

目标实验是让自然模和树从 63 组件推进到 1,000+ 组件，并验证资源是否由形态宽度而不是原始组件数控制。
